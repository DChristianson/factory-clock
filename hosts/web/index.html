Workspace

A workspace is one project's sessions, code, and plans. Every view draws the one selected.

    Or your own: or drop them here. They become a workspace in the list.

    Snagboat's daily event files (events/YYYY-MM-DD.jsonl; in VS Code, Snagboat: Reveal Event Log Folder opens their folder), code and plan files, a beads export, a .workspace.json package, or a project folder, whose code (npm and TypeScript), plans (a beads export, and planning Markdown such as design docs with a Steps or Plan section), and any event files are read together. Files are read in this browser and nothing is sent anywhere: the page's security policy forbids network requests. A folder is read without .git, node_modules, build output, or binary files, at most 20,000 files of up to 2 MB each.

    Project

      Factory Clock is a set of visualizations of coding-agent sessions, with a stage and a shelf of cards to move between them. Every visualizer draws the same workspace its own way. Pick which sessions above, under Sessions. It reads the event logs of Snagboat, a VS Code extension that watches Claude Code and GitHub Copilot sessions.
