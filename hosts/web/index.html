Factory Clock is a set of visualizations of coding-agent sessions, with a stage and a shelf of cards to move between them. Every visualizer draws the same sessions its own way. Pick which sessions above, under Sessions. It reads the event logs of Snagboat, a VS Code extension that watches Claude Code and GitHub Copilot sessions.

or drop the daily files Snagboat writes (events/YYYY-MM-DD.jsonl) here.

or drop its folder here. Its code (npm and TypeScript) and plans (a beads export, and planning Markdown such as design docs with a Steps or Plan section) are read into the explorer beside the sessions.

Files are read in this browser and nothing is sent anywhere: the page's security policy forbids network requests. A project folder is read without .git, node_modules, build output, or binary files, at most 20,000 files of up to 2 MB each. In VS Code, Snagboat: Reveal Event Log Folder opens the folder the event files are in.
